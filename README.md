Telegram Exam Assistant Bot – Documentation

Overview
This application is a versatile Telegram bot that processes tasks and questions submitted as plain text or images. It responds with tailored solutions generated by a remote AI model: qwen3-vl:235b-cloud (hosted via Ollama Cloud or a compatible inference API). All answers are automatically broadcast to every subscribed user, enabling real-time knowledge sharing in study groups, classroom settings, or team channels.

The system uses the DocuPipe API exclusively for optical character recognition (OCR) to extract text from uploaded images. No other OCR services or local vision models are used. Extracted or typed inputs are sent to the qwen3-vl:235b-cloud model alongside a customizable system prompt. This pre-prompt dictates how the AI should behave, meaning you can easily change the prompt in the configuration depending on the kind of task you need it to solve—whether that's generating strict code snippets, summarizing documents, or answering general trivia.

Key Features
- Accepts tasks or questions as text messages or image uploads via Telegram
- Extracts text from images using the DocuPipe OCR API only
- Highly adaptable: Uses customizable pre-prompts to shape the AI's output exactly to your current needs (e.g., specific programming languages, tone, or formatting rules)
- Automatically broadcasts every generated answer to all subscribed users
- Stores subscriber data locally in an SQLite database (subscribers.db)
- Uses the qwen3-vl:235b-cloud model (via remote/Ollama Cloud) for AI-powered generation

Requirements
- Python 3.10 or newer
- A valid Telegram bot token (from @BotFather)
- Access to the DocuPipe OCR API (valid endpoint and credentials)
- Access to the qwen3-vl:235b-cloud model via a compatible Ollama Cloud or remote inference endpoint
- Internet connectivity for Telegram, DocuPipe, and the AI model API

Installation

1. Clone the repository:
   git clone https://github.com/Vitaliy-Wyzer/telegram_agent.git
   cd telegram_agent

2. Create and activate a virtual environment:
   python -m venv .venv
   # Windows (PowerShell):
   .venv\Scripts\Activate.ps1
   # Linux/macOS:
   source .venv/bin/activate

3. Install required packages:
   pip install python-telegram-bot python-dotenv

   (Ensure all dependencies used in src/ modules are satisfied.)

Configuration

- The Telegram bot token must be configured in the application (e.g., via .env or config).
- The AI model endpoint (for qwen3-vl:235b-cloud) and authentication must be set in the AI processing module.
- DocuPipe API credentials or endpoint must be configured in src/image_processor.py.

Running the Bot

From the project root (with virtual environment activated):
python -m src.main

On first run, the bot will:
- Create subscribers.db to track user subscriptions
- Load configuration (token, model endpoint, etc.)
- Begin listening for messages

All non-command text or image messages are processed: text is sent directly to the qwen3-vl:235b-cloud model, while images are first passed to DocuPipe for text extraction, then to the model for solution generation.

Notes
- The bot relies solely on DocuPipe for OCR—no fallback is implemented.
- The AI backend is the qwen3-vl:235b-cloud model, accessed remotely (not a local LLM).
- The subscribers.db file is created automatically and must not be committed to version control.
